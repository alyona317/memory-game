# Memory Game — The Office Edition

Браузерная игра «Мемори» в стиле сериала «Офис». Задача — открыть все пары.

## Как играть

1. Кликните по карточке — она перевернётся.
2. Кликните по второй карточке.
   - Если картинки совпали, обе карточки остаются открытыми.
   - Если нет — через секунду они снова закроются.
3. Игра заканчивается, когда найдены все 8 пар.


## Локальный запуск

### Требования

- [Node.js](https://nodejs.org/) версии 18 или новее (вместе с ним устанавливается npm)

Проверить установленную версию:

```bash
node -v
```

### Шаги

1. Склонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone [ссылка](https://github.com/alyona317/memory-game.git)
   cd memory-game
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Запустите dev-сервер:

   ```bash
   npm run dev
   ```

4. Откройте в браузере адрес, который покажет терминал (обычно http://localhost:5173).
